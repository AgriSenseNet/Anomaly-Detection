# C2 Smart Agriculture Platform

This project contains Sprint 1 work for external API integration and Airflow orchestration.

## Sprint 1 Scope
- Open-Meteo integration
- NASA POWER integration
- SoilGrids integration
- PostgreSQL caching
- Apache Airflow DAG setup

## Folder Structure
- dags/ : Airflow DAG files
- scripts/ : Python scripts for API fetching
- sql/ : database table creation scripts
- docs/evidence/ : screenshots and sprint evidence
